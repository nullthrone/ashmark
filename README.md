# Ashmark

A solo role-play addon for World of Warcraft Forever. Decisions leave a mark: alliances lock out their rivals, behaviour shapes who your character becomes, and alts sharing a surname carry one house's history.

Status: in development. See `docs/DECISIONS.md` for the v1 scope and `docs/research/forever-platform.md` for the platform facts it rests on.

Ashmark started under the working name Embertale.
